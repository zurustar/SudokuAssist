数独アシスト

確定した数字を入力すると、同じ行・列・3×3ブロックからその候補を消します。
さらに枝分かれ・裸のペア／トリオ・隠れペア／トリオ・X-Wing／Swordfish／Jellyfish・XY／XYZ／W-Wing・彩色で候補を削り、 候補が1つになったマスとその数字を置ける場所が1つになったマスを、連鎖が止まるまで自動で確定します。
試し置きや解の一意性を前提とする技法は使わず、論理だけで断定できるものに限っています。 自動確定したマスにカーソルを重ねると、確定の理由が出ます。

5 自分の入力 5 自動確定

入力待ち

確定 0 / 81　（自分 0・自動 0）
残り 81 マス

使われた技法

    数字を確定
    セルを選んで 1〜9、または候補の数字を直接クリック
    取り消し
    0 / Del / Back
    移動
    ←↑↓→
    履歴
